# Probability Experiments

A report exploring probability concepts through interactive simulations of Bayes' theorem and the binomial probability distribution.

## Contents

### Bayes' Theorem and Inverse Probability

The first section examines how sensitivity, specificity, and the base rate affect the probability that a state is present after a positive diagnostic signal.

It uses Bayes' theorem:

\[
P(S \mid D) = \frac{P(D \mid S)P(S)}{P(D)}
\]

The report compares five combinations of sensitivity, specificity, and base rate, then summarizes their posterior probabilities.

### Binomial Probability Distribution

The second section explores how the number of trials \(n\) and probability of success \(p\) shape a binomial distribution:

\[
P(X = x) = \binom{n}{x}p^x(1-p)^{n-x}
\]

It presents six example cases, including distributions that are nearly symmetric, skewed, concentrated near zero, and reduced to a single outcome.

## Key Takeaways

- A positive test result does not determine probability on its own; the base rate and test specificity also matter.
- Binomial distributions change shape as the number of trials and probability of success change.
- When \(p\) is near 0.5, the distribution can be nearly symmetric.
- When \(p\) approaches 0 or 1, probability concentrates toward the corresponding end of the distribution.
